# Docs layout
- `journal/` - Project Journal entries, weekly from Week 6 (`journal_NN_weeks_X-Y.md` is the source; build the .docx with `python tools/build_journal.py <file.md>`). Journal 1 (Weeks 1-3) and 2 (Weeks 4-5) cover more than one week.
- `meetings/` - one-page notes per meeting or Teams update (decisions and actions).
- `weekly/` - weekly management updates (mirrors the Notion "Weekly management update" tasks).
- `reading_list.md` - literature list. The literature review log (5 priority-paper summaries) is a Claude doc: https://claude.ai/artifact/YZEF4XMXGPXcQR44AtC7tS
